## 1. 平台简介

本平台是面向 Python 编程教学的交互式学习系统，包含三大课堂：

| 课堂 | 定位 | 核心体验 |
|------|------|---------|
| **学习课堂** | 课程学习 | Jupyter 式笔记本界面：文字讲解、可执行代码、图片、视频，支持拖拽排序与 LaTeX 数学公式 |
| **训练课堂** | 巩固练习 | 编程练习题自动判分、渐进式提示（有积分惩罚）、提交历史与积分统计 |
| **考试课堂** | 考核评估 | 限时考试（服务端强制计时）、四种题型、自动保存、成绩分析、证书颁发 |

配套能力：AI 学习助手（可查询真实课程资料回答问题）、AI 内容生成（教师/管理员）、证书在线验证。

**角色说明**：学生（注册即得）、教师（由管理员创建，可编辑自己的课程）、管理员（后台管理 + AI 生成）。

## 2. 快速上手

### 2.1 注册与登录

1. 打开平台首页，点击导航栏 **Login** → 注册页 **Create Account**。
2. 填写用户名、邮箱、密码（≥8 位且不能过于简单）。**所有人注册的账号都是学生账号**；教师账号请联系管理员开通。
3. 注册成功后自动登录，进入个人仪表盘（Dashboard）。

### 2.2 个人仪表盘

学生仪表盘展示：已选课程、最近学习记录、提交统计（提交数/通过数）、考试统计（参加/通过）、最近 7 天活跃度、课程完成进度。

### 2.3 账号安全

- 登录支持"记住跳转页"（仅限站内地址，外部链接会被拦截）。
- 退出登录：右上角用户名 → **Logout**（按钮式，防止误触发）。
- 忘记密码请联系管理员重置。

## 3. 学习课堂

### 3.1 选课

1. 导航栏进入 **Learning / Courses**，浏览已发布课程（支持难度筛选与搜索）。
2. 进入课程详情页查看章节与课程单元列表，点击 **Enroll** 选课。
3. 已选课程中，已发布的课程单元显示 **Start** 按钮可直接进入。

### 3.2 Notebook 学习界面

课程单元采用 Jupyter 式单元格组织，包含四种单元格：

| 类型 | 说明 |
|------|------|
| 📝 文本 | Markdown 排版，支持 LaTeX 数学公式（KaTeX 渲染） |
| 💻 代码 | **真实 Jupyter 内核执行**，支持富输出（文本/图像/错误回溯） |
| 🖼 图片 | 配图与说明文字 |
| 🎬 视频 | YouTube/Vimeo 嵌入或直链视频 |

**运行代码**：代码单元格点击 **Run**，代码在属于你的**真实 Jupyter 内核会话**中执行（每个学员每门课一个会话）：

- **变量跨单元格持久**：`x = 10` 在一个单元格定义后，后面任何单元格都能用；
- **富输出**：matplotlib 绘图直接显示为图像；输出、错误回溯与 Jupyter 一致；
- **In[n] 执行计数**随每次运行递增；
- **重启内核**：单元格上方「重启内核」按钮清空所有变量（相当于 Jupyter 的 Kernel → Restart）；
- **超时保护**：单次执行超过 15 秒会被中断（变量保留）；若中断无法恢复，内核自动重启并提示；
- 空闲会话会被自动回收（约 15 分钟无操作后变量清空）；
- 代码在**隔离的内核环境**中运行（生产环境为 Docker 容器，网络与资源受限），不会影响服务器与其他学员。

**进度记录**：已选课学生的每次代码执行都会被记录；顶部进度条按"已执行代码单元格占比"显示，完成全部学习后可点击 **Mark Complete** 完成该课程单元；全部课程单元完成后课程显示"Course Complete"。

## 4. 训练课堂

### 4.1 浏览练习

导航栏进入 **Training / Exercises**（需登录）。练习按难度从易到难排列（初级 → 中级 → 高级），支持按课程、难度、关键词筛选。

### 4.2 作答与自动判分

1. 打开练习详情页，阅读题目描述，在代码编辑区编写程序（支持起始代码模板）。
2. 点击 **Submit** 提交。系统在沙箱中运行你的代码并执行隐藏测试用例。
3. 结果立即可见：通过/失败的测试数、得分、运行输出、错误信息。

判分支持两种题型：**标准输入输出型**（用 `input()` 读取、`print()` 输出）和**函数型**（定义指定函数，测试用例直接调用并比对返回值）。

### 4.3 提示与积分惩罚

- 每个练习配有渐进式提示；**首次查看某条提示会扣除相应积分**（提示上标明惩罚分值），重复查看不重复扣分。
- 练习通过后获得满分（基础分 − 已用提示的惩罚分之和）；**同一练习只有首次通过计入积分**，重复练习不会重复加分。

### 4.4 提交历史与进度

- 练习页展示最近 5 次提交，可查看每次的完整测试详情。
- **My Progress** 页汇总：总积分、已完成练习数、提交统计。

## 5. 考试课堂

### 5.1 开始考试

1. 进入 **Examination** 列表，选择已发布的考试。
2. 详情页确认时长、尝试次数上限，点击 **开始考试**。
3. 系统创建一次"尝试"并进入答题界面。**考试计时在服务端强制**：即使刷新页面，剩余时间也不会重置；倒计时归零后无法再保存答案。

### 5.2 答题界面

| 题型 | 作答方式 |
|------|---------|
| 选择题 | 单选 A/B/C/D |
| 判断题 | 对/错 |
| 编程题 | 在线编写代码，交卷时自动运行测试用例判分 |
| 简答题 | 文本作答（支持字数限制） |

- **自动保存**：答案实时保存（约 2 秒防抖），意外断网/刷新不丢失。
- 时间到后请立即 **提交试卷**；提交过程原子化——即使判分中途出错，也不会把你的尝试"锁死"，可重新提交。

### 5.3 成绩与结果

交卷后进入结果页：总分、通过与否（按通过分数线）、每题得分与解析。简答题在 AI 可用时自动评分；否则标记为"待人工评阅"，管理员评阅后成绩更新。

### 5.4 补考规则

- 每次考试有**最大尝试次数**（默认 3 次），超过后无法再开始。
- 同一时间只保留一次"进行中"的尝试；再次点击开始会回到进行中的答题。

## 6. AI 学习助手

导航栏进入 **Chat**：

- **对话式问答**：Python 学习问题实时解答；支持多会话管理（新建/切换/删除）。
- **资料级回答**：助手可以**查询平台真实课程资料（ClassLib notebook）**——问"1.2 节讲了什么"时，它会读取对应小节内容后回答，并注明出处，而不是凭空生成。
- **资源推荐**：回答附带相关学习资料推荐。
- 受日额度控制：AI 用量达到当日上限时，助手会提示次日再试。

## 7. 证书

### 7.1 下载证书

考试通过后，结果页出现 **下载证书** 按钮：

1. 点击下载 PDF 证书（首次点击自动生成，之后复用同一份）。
2. 证书含：学员姓名、考试名称、成绩、通过线、颁发日期、**32 位验证码**。

### 7.2 在线验证

任何人凭验证码可在 `/examination/certificates/<验证码>/` 页面查验证书真伪（显示学员、考试、成绩与颁发时间）。无效验证码显示验证失败提示。

## 8. 教师功能

### 8.1 教师账号如何开通与登录

平台采用「学生自助注册、教师统一开通」的账号体系：

1. **开通账号**：由管理员在服务器上执行（或由平台管理员代开）：
   ```bash
   python manage.py create_instructor --username 你的工号 --password 初始密码
   # 或生成随机密码（打印一次）：python manage.py create_instructor --username 你的工号
   # 需同时开通后台权限：加 --make-superuser
   ```
2. **登录**：使用与普通登录相同的入口——右上角 **Login**，输入教师用户名与密码。
3. 登录后导航栏出现 **「教学台」** 入口，即教师工作台。

> 说明：注册页只开放学生注册（防越权设计）。教师账号一经开通，后续可自行在「个人资料」页修改邮箱等信息。

### 8.2 教师工作台（导航栏「教学台」）

- **我的课程**：名下课程列表（草稿/已发布状态、章节数、学员数）；
- **新建课程**（支持 AI 辅助设计）：
  - 手动：填写标题/简介/难度，创建空草稿课程；
  - **AI 辅助（默认开启）**：勾选「AI 辅助设计课程」，选择章节数——提交后 AI 自动生成**章节 + 课程单元大纲**，并在 ClassLib 教学文档中**自动检索相关素材**用于接地（可关闭）；
- 大纲确认页：逐单元点「生成内容」（AI 基于素材生成文本+代码单元格，重新生成会覆盖）、或「一键生成全部」；生成后可跳编辑器微调；
- 每门课程的「管理」进入课程详情页的**教师工作区**：
  - **发布课程 / 下线为草稿**（一键切换）；
  - **添加章节**（标题 + 简介）；
  - **新建课程单元**（选择章节 + 标题）——创建后直接进入笔记本编辑器；
  - 每个课程单元可单独**发布 / 下线**（草稿单元学生不可见）；
  - **查看学员进度**：名单、选课时间、完成单元数、进度条、完成状态。

> AI 生成消耗 API 额度（受每日成本上限保护）；无 AI 密钥时自动回退为手动流程。

### 8.3 笔记本编辑器（课程单元编辑）

- 进入已发布/草稿课程单元后点击 **Edit Lesson**。
- **单元格操作**：添加（文本/代码/图片/视频）、编辑、删除、**拖拽排序**（拖动后点击 Save Cell Order 保存）。
- 文本单元格支持 Markdown + LaTeX 预览；代码单元格点击 Run 可试运行（结果不会写入课程内容）。
- **版本快照**：每次保存自动留存版本（后台可查，提供恢复 API）。

### 8.4 创建练习（训练课堂）

练习列表页点击 **创建练习**（教师可见）：

- 填写标题、难度、满分、所属课程（可选）、Markdown 题目描述；
- 起始代码模板与参考答案；
- **测试用例（JSON）**：函数式 `[{"input": "add(2, 3)", "expected": 5}]` 或 stdin/stdout 式 `[{"input": "2\n3", "expected_output": "5"}]`（同一练习不混用）；
- 渐进提示最多 3 条，每条可设查看扣分；
- 创建后**立即对学生可见**。

### 8.5 考试管理（考试课堂）

考试列表页点击 **考试管理**：

- 查看自己创建的考试（题目数、参加人次）；
- **发布 / 下线**：AI 生成的考试（`generate_exam` 命令）保存为草稿，在此审核后一键发布；
- 发布前请先在详情页核对题目；编程题建议用参考答案试跑测试用例。

### 8.6 注意事项

- 视频单元格的"Manim Generated"类型对应 AI 生成的动画视频。
- 代码单元格中请勿保存学生个人运行输出；学生执行结果不会回写。
- 草稿内容仅教师与管理员可见，学生无任何入口。

## 9. 管理员功能

### 9.1 后台账号与密码管理

后台入口为 `/admin`（需 `is_staff` 权限）。账号管理全部通过管理命令完成：

```bash
# 创建超级用户（交互式输入密码）
python manage.py createsuperuser --settings=config.settings.development

# 修改任意用户密码（含 admin）——忘记密码时用这个
python manage.py changepassword admin --settings=config.settings.development

# 开通教师账号（随机密码会打印一次；加 --make-superuser 同时授予后台权限）
python manage.py create_instructor --username 工号 --make-superuser --settings=config.settings.development
```

> 安全提醒：生产环境部署后第一件事就是 `changepassword` 修改所有初始密码；样例数据导入产生的密码（如 `instructor123`）属开发遗留，严禁在生产使用。

### 9.2 Django 后台（/admin）

- 用户管理：创建教师账号（学生账号仅可自注册）、重置密码、角色调整。
- 考试管理：**审阅 AI 生成的考试草稿并发布**；简答题人工评阅（评阅后成绩更新）。
- 内容管理：课程/章节/课程单元/练习/提示/考试题目全量管理；单元格版本快照查看。

### 9.3 AI 内容生成（管理命令）

管理员在服务器上执行（需配置 AI 密钥）：

```bash
# 生成课程单元（可指定 ClassLib notebook 的某节作为素材）
python manage.py generate_lesson "数字常量" --notebook 第一课_基本数据结构.ipynb --section 1.1

# 生成练习题（含测试用例与提示，直接发布）
python manage.py generate_exercises --topic "函数" --count 5 --difficulty intermediate

# 生成考试（保存为草稿，人工审核后发布）
python manage.py generate_exam --course python-basics --question-count 20

# 生成 Manim 动画脚本（可选 --render 直接渲染视频）
python manage.py generate_video_script "列表推导式" --render --quality medium

# AI 连通性检查
python manage.py test_ai_agents
```

## 10. 常见问题（FAQ）

**Q：注册时提示密码不合格？**
A：密码需 ≥8 位，且不能是常见弱密码、不能与用户名/邮箱相似。

**Q：训练/考试提交时报"import of 'os' is not allowed"？**
A：训练与考试的**判分沙箱**出于安全考虑仅允许白名单模块（math/random/json/re/collections 等），且不能进行文件/网络/系统操作。学习课堂不受此限制（真实 Jupyter 内核，完整 Python 环境）。

**Q：代码执行到一半提示超时？**
A：学习课堂单次执行超过 15 秒会被中断（变量保留）；训练/考试判分超时则直接终止并标记超时。请检查程序是否有无限循环。

**Q：学习课堂里能 import 什么？**
A：学习课堂使用真实 Jupyter 内核——完整 Python 环境（含 numpy/matplotlib/pandas），变量跨单元格保留。训练/考试的判分沙箱仍是受限环境（白名单模块）。

**Q：考试页面刷新后时间会重置吗？**
A：不会。剩余时间由服务器按开始时间计算，刷新、重启浏览器都不影响。

**Q：练习明明做对了却显示"运行中"？**
A：在启用异步判分的部署中，提交先显示"运行中"，后台判分完成后刷新即可看到结果。

**Q：为什么重复提交同一练习不再加分？**
A：防刷设计：每个练习只有首次通过计入积分与完成数。

**Q：AI 助手回答的内容可靠吗？**
A：涉及课程资料的问题，助手会先查询平台真实 notebook 内容再作答并注明出处；仍建议以课程内容为准。

## 11. 故障排查

| 现象 | 处理 |
|------|------|
| 登录（含后台）提示"CSRF 验证失败" | ① 固定使用**同一个地址**访问（`localhost` 与 `127.0.0.1` 不要混用）；② 清除浏览器该站点的 Cookie 后重试；③ 若通过局域网 IP/域名访问：在 `.env` 的 `ALLOWED_HOSTS` 加上该地址，并在 `CSRF_TRUSTED_ORIGINS` 加上完整来源（如 `http://192.168.1.10:8000`）后重启服务 |
| 登录后跳转 404 | 清理浏览器缓存的旧书签，从首页重新进入 |
| AI 助手提示"遇到问题" | 稍后重试；若持续，联系管理员检查 AI 服务配置与当日额度 |
| 视频单元格无法播放 | 检查网络能否访问 YouTube/Vimeo；自建视频请确认链接有效 |
| 证书下载 403 | 该次考试未达到通过分数线，证书仅向通过者颁发 |
| 页面显示"操作失败，请重试" | 服务器遇到临时错误（详细信息已记录日志），稍后重试；持续出现请联系管理员 |
| 图片上传失败 | 头像限 5MB 且必须为图片格式 |
